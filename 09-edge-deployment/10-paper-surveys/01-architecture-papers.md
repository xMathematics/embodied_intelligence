# 10.1 体系结构与并行计算经典

## 1. "Computer Architecture: A Quantitative Approach" (6th Ed.)

| 项目 | 内容 |
|------|------|
| 作者 | Hennessy & Patterson (图灵奖) |
| 类型 | 教材 |
| 核心贡献 | 量化分析方法论 |
| 机器人价值 | 评估机器人平台CPU/GPU性能瓶颈 |

## 2. "Programming Massively Parallel Processors" (4th Ed.)

| 项目 | 内容 |
|------|------|
| 作者 | Kirk & Hwu |
| 类型 | 教材 |
| 核心贡献 | CUDA编程系统教程 |
| 机器人价值 | 学习加速传感器数据处理 |

## 3. Amdahl's Law (1967)

| 项目 | 内容 |
|------|------|
| 作者 | Amdahl |
| 核心 | 并行加速比上限: S = 1/((1-P)+P/N) |
| 机器人价值 | 评估并行化潜力, 定位串行瓶颈 |

## 4. Gustafson's Law (1988)

| 项目 | 内容 |
|------|------|
| 作者 | Gustafson |
| 核心 | 弱扩展下近线性加速: S = N - (N-1)·s |
| 机器人价值 | 大规模仿真中并行收益评估 |
