# 8.5 OpenVINO

## 1. 核心特性

| 特性 | 说明 | 机器人价值 |
|------|------|-----------|
| CPU优化 | Intel指令集深度优化 | Intel NUC推理 |
| iGPU加速 | Intel集成显卡推理 | 无需独立GPU |
| 模型优化器 | 转换+优化+量化 | 简化部署 |
| 异构执行 | 自动分配最优硬件 | CPU+iGPU协同 |

## 2. 在机器人中的应用

- **Intel NUC机器人**: 感知模型优化
- **视觉检测**: YOLO在NUC上高效运行
- **RealSense集成**: Intel生态端到端
