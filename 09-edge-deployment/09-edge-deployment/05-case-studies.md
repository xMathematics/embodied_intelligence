# 9.5 机器人部署实战案例

## 案例1: 轮式服务机器人视觉导航

**硬件**: Jetson Orin NX + RealSense D435 + 轮式底盘

**架构**:
```
RealSense → YOLO TensorRT → 路径规划(A*/DWA) → 速度指令
  (5ms)       (5ms INT8)       (10ms)           (CAN)
```

**性能**: 端到端<30ms, 功耗12-18W, 续航>8h

## 案例2: 四足机器人自主避障

**硬件**: Jetson Orin NX + 双目 + LiDAR + IMU + 12电机(CAN FD)

**架构**:
```
双目+LiDAR+IMU → 多模态感知(GPU) → 地形分析 → 步态→关节控制
  (15ms)           (15ms)          (5ms)     (MPC 1kHz)
```

**性能**: 端到端<50ms, 功耗15-25W, 续航6-10h

## 案例3: 机械臂视觉抓取

**硬件**: Intel NUC 13 + Hailo-8 + RGB-D (眼在手)

**架构**:
```
RGB-D → OpenCV预处理 → Hailo-8推理(YOLO+SAM) → 6D位姿→运动规划→力控
  (8ms)      (3ms)           (8ms)             (20ms)    (10ms)
```

**性能**: 端到端<50ms, 功耗28W, 抓取成功率95%+

## 经验总结

1. **先做延迟预算** — 开发前明确端到端目标
2. **ROS2优先** — 推理模块封装为ROS2 Node
3. **从简单开始** — 单模型验证后再加复杂度
4. **功耗测量** — 使用板载传感器实时监测
5. **持续验证** — 实际机器人测试不可替代
