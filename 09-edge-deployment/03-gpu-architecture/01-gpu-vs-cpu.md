# 3.1 GPU vs CPU架构差异

## 1. 设计哲学的根本差异

```
CPU设计哲学: 低延迟 (Latency-Optimized)
┌─────────────────────────────────────────┐
│  复杂控制器 (分支预测, OoO)              │
│  ┌────┐ ┌────┐ ┌────┐ ┌────┐ ┌────┐   │
│  │Core│ │Core│ │Core│ │Core│ │Cache│   │
│  │    │ │    │ │    │ │    │ │     │   │
│  └────┘ └────┘ └────┘ └────┘ └────┘   │
│  ★ 少量但强大的核心                       │
└─────────────────────────────────────────┘

GPU设计哲学: 高吞吐 (Throughput-Optimized)
┌─────────────────────────────────────────┐
│              SIMT控制器                   │
│  ┌──┐ ┌──┐ ┌──┐ ┌──┐ ... ┌──┐          │
│  │ALU│ │ALU│ │ALU│ │ALU│    │ALU│        │
│  │ALU│ │ALU│ │ALU│ │ALU│    │ALU│        │
│  │ALU│ │ALU│ │ALU│ │ALU│    │ALU│        │
│  │ALU│ │ALU│ │ALU│ │ALU│    │ALU│        │
│  └──┘ └──┘ └──┘ └──┘     └──┘          │
│  ★ 大量但简单的ALU                       │
└─────────────────────────────────────────┘
```

### 量化对比

| 指标 | CPU (i9-13900K) | GPU (RTX 4090) | 比例 |
|------|----------------|---------------|------|
| 核心数 | 24 (8P+16E) | 16384 CUDA Core | 1:683 |
| 频率 | 5.8 GHz | 2.5 GHz | 2.3× |
| FP32峰值 | ~2 TFLOPS | ~83 TFLOPS | 1:41 |
| 内存带宽 | 100 GB/s | 1.0 TB/s (GDDR6X) | 1:10 |
| 内存大小 | 64 GB | 24 GB | 2.7:1 |
| TDP | 125W | 450W | 1:3.6 |
| 每瓦性能 | ~16 GFLOPS/W | ~184 GFLOPS/W | 1:11.5 |

## 2. 各自适合的工作负载

### CPU适合 (控制密集)
- 操作系统和任务调度
- ROS2通信 (消息路由)
- 控制循环 (PD/PID, 状态机)
- 分支密集的逻辑判断
- 单线程依赖的串行计算

### GPU适合 (数据密集)
- 图像/视频处理 (卷积, 滤波)
- 神经网络推理 (CNN, Transformer)
- 点云处理 (配准, 分割)
- 矩阵运算 (EKF大矩阵)
- 物理仿真 (碰撞检测, 粒子系统)

### 在机器人中的分工

```
┌─────────────────────────────────────────────┐
│             机器人计算系统                     │
├──────────┬──────────────────┬────────────────┤
│  CPU (控制) │  GPU (感知)      │  NPU (推理)   │
├──────────┼──────────────────┼────────────────┤
│ ROS2通信  │ CNN推理          │ INT8模型推理   │
│ 控制循环  │ 图像预处理        │ 唤醒词检测     │
│ 路径规划  │ 点云配准          │ 轻量分类       │
│ 状态机    │ 特征提取          │               │
│ 日志记录  │ 渲染/仿真         │               │
│ 文件I/O   │                  │               │
└──────────┴──────────────────┴────────────────┘
```

## 3. 在具身智能中的应用

| 场景 | 使用CPU | 使用GPU | 原因 |
|------|--------|---------|------|
| 避障 | 策略选择 | 视觉感知 | CPU逻辑, GPU视觉 |
| SLAM | 后端优化 | 前端特征 | CPU地图维护, GPU特征 |
| 抓取 | 运动规划 | 6D姿态预测 | CPU规划, GPU预测 |
| 导航 | 全局路径 | BEV感知 | CPU规划, GPU感知 |
