# 3.6 异构计算协同

## 1. 为什么要异构计算

```
每个计算单元各有优势:
┌─────────┬──────────┬───────────┐
│  单元    │  强项     │  弱项      │
├─────────┼──────────┼───────────┤
│  CPU    │  控制流   │  并行计算  │
│  GPU    │  数据并行  │  能耗高   │
│  NPU    │  能效比   │  灵活性差  │
│  DLA    │  低功耗推理 │  仅CNN   │
│  FPGA   │  可重构   │  开发难   │
└─────────┴──────────┴───────────┘
```

### 任务分配

| 计算单元 | 负责任务 | 功耗 |
|---------|---------|------|
| CPU (12核) | ROS2通信, 控制循环, 路径规划 | 5-10W |
| GPU (Ampere) | YOLO推理, 点云分割 | 15-30W |
| DLA v2.0 | 轻量模型推理 (分类, 检测) | 1-3W |
| PVA | 图像缩放, 颜色转换, 光流 | 0.5W |

## 3. 异构流水线设计

### 3.1 完整感知-规划-控制流水线

```
时间 ──────────────────────────────────────────────→
┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐
│相机   │ │PVA   │ │GPU   │ │CPU   │ │CPU   │
│DMA    │ │预处理 │ │推理  │ │后处理│ │控制  │
│→内存  │ │(缩放) │ │YOLO  │ │(NMS) │ │(避障)│
└──────┘ └──────┘ └──────┘ └──────┘ └──────┘
  ~1ms     ~1ms     ~15ms    ~2ms    ~1ms

DLA (并行): ┌──────────┐
            │轻量分类   │
            │(场景识别) │
            └──────────┘
              ~2ms

总延迟: ~20ms (50Hz) ✅
```

### 3.2 任务调度策略

```cpp
// 异构任务调度伪代码
void robot_pipeline() {
    // 1. DLA处理简单任务 (低功耗)
    dla_submit(classify_task);       // 场景识别
    
    // 2. PVA做图像预处理
    pva_submit(resize_task);         // 缩放图像
    
    // 3. GPU做主要推理
    gpu_submit(detection_task);      // YOLO检测
    
    // 4. CPU等待所有完成并控制
    dla_wait();
    gpu_wait();
    
    // 5. 控制计算
    cpu_control(detection_result, classify_result);
}
```

## 4. 负载均衡策略

| 策略 | 说明 | 适用场景 |
|------|------|---------|
| **DLA优先** | 轻量模型交给DLA | 常开的前置检测 |
| **GPU+NPU协同** | GPU做大模型, NPU做小模型 | 多模型并行 |
| **动态切换** | 低功耗时只用DLA+CPU | 待机/低负载 |
| **帧率调节** | 根据场景复杂度调整 | 室外固定帧率, 室内降低 |
