# 4.3 并行算法设计模式

## 1. 归约 (Reduction)

### 原理
将多个值合并为一个值 (求和、最大值、最小值)。

### 树形归约
```
输入: [3, 1, 7, 2, 5, 8, 4, 6]
Step 1 (4个线程):  [4, 9, 13, 10]  (两两相加)
Step 2 (2个线程):  [13, 23]
Step 3 (1个线程):  [36]
总步数: log₂(8) = 3 步
```

### 在机器人中
- 点云质心计算
- 神经网络全局池化
- 粒子滤波的有效粒子数

## 2. 前缀和 (Scan / Prefix Sum)

### 原理
计算每个位置之前所有元素的累积和。

```
输入: [1, 2, 3, 4, 5, 6, 7, 8]
输出: [1, 3, 6, 10, 15, 21, 28, 36]
```

### 在机器人中
- 路径规划的代价累积
- 体素网格的索引计算
- 并行排序的基础

## 3. MapReduce

```
Map阶段: 每个元素独立处理
  [数据] → Map(f) → [中间结果]

Reduce阶段: 合并相同Key的结果
  [中间结果] → Reduce(g) → [最终结果]
```

### 在机器人中
- 多传感器数据的独立处理(Map) + 融合(Reduce)
- SLAM中特征的独立提取(Map) + 匹配(Reduce)

## 4. 分治

```
问题分解: 大问题 → 子问题1, 子问题2, ...
递归求解: 并行求解每个子问题
结果合并: 子结果 → 最终结果
```

### 在机器人中
- 碰撞检测的空间分割 (BVH树)
- 路径规划的分区搜索
