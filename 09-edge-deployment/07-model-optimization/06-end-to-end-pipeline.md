# 7.6 综合优化管线

## 1. 推荐优化流程

```
原始模型 (FP32, 100%)
    │
    1. 结构化剪枝 (移除30-50%通道)
    │   └── Fine-tuning恢复精度
    │
    2. 知识蒸馏 (Teacher=原模型, Student=剪枝后)
    │   └── 精度恢复到接近原模型
    │
    3. INT8量化 (PTQ或QAT)
    │   └── 验证精度损失<1%
    │
    ▼
部署模型 (INT8, ~25%大小, 3-4×加速)
```

## 2. 完整案例: DINOv2部署

```
DINOv2 ViT-B (机器人场景理解)
├── 原始: FP32, 344MB, 50ms (Jetson Orin)
├── Step 1: Attention头剪枝 12→8头
│   ├── 大小: 260MB, 延迟: 40ms
│   └── 精度: -0.3%
├── Step 2: 蒸馏到TinyViT-5M
│   ├── 大小: 21MB, 延迟: 8ms
│   └── 精度: -1.2%
├── Step 3: INT8量化
│   ├── 大小: 5.5MB, 延迟: 3ms
│   └── 精度: -1.5%
└── 最终: 大小减少98%, 加速16×, 精度损失1.5%
```

## 3. 优化决策指南

| 情况 | 推荐优化 | 理由 |
|------|---------|------|
| 模型太大放不进显存 | 量化+剪枝 | 最大压缩比 |
| 推理延迟不满足 | 量化+轻量架构 | 最大加速 |
| 精度不够 | 蒸馏 | 保持精度 |
| 从零开始 | 轻量架构 | 天然高效 |
| 已有FP32模型 | 量化(PTQ) | 最简单 |
