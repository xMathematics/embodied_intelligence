# 7.5 神经架构搜索(NAS)

## 1. 搜索方法对比

| 方法 | 搜索成本 | 精度 | 机器人适用性 |
|------|---------|------|-------------|
| 强化学习NAS | 数千GPU天 | 最高 | ❌ 成本太高 |
| 可微分NAS(DARTS) | 数GPU天 | 中 | ✅ |
| One-Shot(OFA) | 中(一次训练) | 高 | ✅ 推荐 |
| Zero-Shot | 极低 | 中 | ✅ 快速原型 |

## 2. Once-for-All (OFA)

```
训练一次超网络:
┌─────────────────────────────────┐
│       超网络 (Supernet)          │
│  ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐     │
│  │C3 │ │C5 │ │C7 │ │DW │ │     │
│  └──┘ └──┘ └──┘ └──┘ └──┘     │
│  ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐     │
│  │16 │ │32 │ │64 │ │128│ │     │
│  └──┘ └──┘ └──┘ └──┘ └──┘     │
└─────────────────────────────────┘

部署时直接选择子网络:
Jetson Nano → 小网络 (0.5 GMACs)
Jetson Orin → 大网络 (4 GMACs)
```
