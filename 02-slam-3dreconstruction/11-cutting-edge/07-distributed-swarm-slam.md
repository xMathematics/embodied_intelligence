# 11.7 分布式与群体SLAM

## 1. 概述

分布式SLAM（Distributed SLAM）和群体SLAM（Swarm SLAM）涉及多个机器人协作完成定位和建图任务。与单机器人SLAM相比，多机器人SLAM可以更快地覆盖更大区域，提供更高的鲁棒性和可扩展性。

## 2. 多机器人SLAM框架

### 2.1 集中式 vs 分布式 vs 分散式

| 框架 | 通信模式 | 计算模式 | 可扩展性 | 鲁棒性 | 代表系统 |
|------|----------|----------|----------|--------|----------|
| **集中式** | 所有数据→中心 | 中心统一计算 | 差 | 差 | C2TAM |
| **分布式** | 各机部分通信 | 各机独立计算 | 好 | 好 | DDF-SAM |
| **分散式** | 仅邻居通信 | 各机独立计算 | 极好 | 极好 | Swarm-SLAM |
| **混合式** | 分层通信 | 局部+全局 | 好 | 好 | Kimera-Multi |

### 2.2 集中式SLAM

**流程**：
```
机器人1 → 局部数据 →│
机器人2 → 局部数据 →├→ 中心服务器 → 全局地图
机器人3 → 局部数据 →│              ↓
                         反馈到各机器人
```

**优势**：
- 全局信息全知
- 简单的数据融合
- 全局最优性保证

**劣势**：
- 中心服务器瓶颈
- 单点故障
- 通信负载大
- 可扩展性差

### 2.3 分布式SLAM

**核心挑战**：
1. **通信拓扑**：谁和谁通信、何时通信
2. **一致性维护**：各机器人保持一致的全局视图
3. **数据关联**：无需全知情况下的数据关联
4. **冲突解决**：各机器人地图冲突时的一致性维护

## 3. 分布式因子图SLAM

### 3.1 DDF-SAM

**DDF-SAM**（Cunningham et al., 2012）是分布式因子图SLAM的奠基工作。

**核心机制**：
1. 每个机器人维护本地因子图
2. 生成摘要（Summary）发送给其他机器人
3. 摘要编码：边际信息矩阵 $[\mathbf{\Omega}_i, \boldsymbol{\xi}_i]$
4. 各机器人整合收到的摘要到本地图

**分布式更新**：
```
机器人i: 
  本地观测 → 更新本地因子图
  选择关键信息 → 生成摘要
  广播摘要到邻居

机器人j(接收):
  收到摘要 → 作为先验因子添加
  优化本地图
```

### 3.2 DOOR-SLAM

**DOOR-SLAM**（Lajoie et al., 2020）：
- 分布式在线SLAM
- 鲁棒的外点处理
- 按需通信（只在必要时交换数据）

**关键特性**：
- **分布式回环检测**：各机器人独立检测
- **鲁棒匹配**：RANSAC + 一致性检查
- **按需通信**：减少带宽消耗

## 4. 群体SLAM

### 4.1 Swarm-SLAM

**Swarm-SLAM**（Lajoie et al., 2023）专门为大规模机器人群体设计。

**核心技术**：
1. **分散式数据关联**：不依赖中心节点
2. **对等通信**：只与邻居机器人通信
3. **分布式优化**：使用ADMM分布式优化算法
4. **共识机制**：各机器人在重叠区域达成一致

**特点**：
- 机器人数量可扩展到100+
- 通信带宽需求低
- 对机器人加入/离开鲁棒

### 4.2 群体SLAM的挑战

| 挑战 | 描述 | 当前方法 |
|------|------|----------|
| **通信带宽** | 大量机器人产生大量数据 | 选择性通信、压缩 |
| **计算负载** | 群体规模大导致计算爆炸 | 分布式计算 |
| **数据关联** | 不知道谁看到了什么 | 分布式匹配 |
| **一致性** | 不同地图冲突 | 共识算法 |
| **同步** | 时间戳对齐 | 分布式时钟 |

## 5. 回环检测与地图融合

### 5.1 跨机器人回环

当两个或更多机器人相遇或通过通信发现共同区域时，建立跨机器人约束。

**匹配方法**：
1. **基于外观**：BoW/NetVLAD全局描述子
2. **基于几何**：ICP/NDT扫描匹配
3. **基于语义**：共同语义地标匹配

### 5.2 地图融合策略

**相对位姿估计**：

$$ \mathbf{T}_{AB} = \arg\min_{\mathbf{T}} \| \mathbf{T} \mathbf{p}_i^A - \mathbf{q}_j^B \|^2 $$

**一致性检查**：
- 内点比例验证
- 互惠匹配验证
- 时序一致性验证

**冲突处理**：
- 基于置信度的加权融合
- 鲁棒优化（DCS, Switchable Constraints）
- 多数投票机制

## 6. 代表性系统对比

| 系统 | 框架 | 通信方式 | 最大机器人数 | 地图类型 | 回环 |
|------|------|----------|-------------|----------|------|
| DDF-SAM | 分布式 | 广播摘要 | 10+ | 稀疏特征 | 是 |
| DOOR-SLAM | 分布式 | 点对点 | 20+ | 稀疏特征 | 是 |
| Kimera-Multi | 混合式 | 广播+点对点 | 10+ | 度量+语义 | 是 |
| Swarm-SLAM | 分散式 | 邻居 | 100+ | 稀疏 | 是 |
| C2TAM | 集中式 | 全部→中心 | 5+ | 稀疏 | 是 |

## 7. 通信与带宽优化

### 7.1 通信策略

| 策略 | 描述 | 带宽节省 |
|------|------|----------|
| **按需通信** | 只在需要时通信 | 高 |
| **事件触发** | 仅在有重要更新时通信 | 中-高 |
| **周期性通信** | 固定间隔通信 | 低-中 |
| **广播压缩** | 压缩后广播 | 中 |

### 7.2 地图压缩

分布式场景中的地图压缩：
- 关键帧选择（只传最关键帧）
- 特征压缩（量化和子采样）
- 信息过滤（只传摘要信息）

## 8. 未来方向

- **超大群体SLAM**：1000+机器人的SLAM
- **异构群体SLAM**：不同类型传感器的机器人协作
- **空地协同SLAM**：无人机+地面机器人
- **人机协作SLAM**：人与机器人共同建图
- **通信受限SLAM**：在水下/地下等通信受限场景
