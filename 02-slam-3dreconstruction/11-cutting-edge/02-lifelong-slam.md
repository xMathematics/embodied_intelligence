# 11.2 终身SLAM与长期自主

## 1. 概述

终身SLAM（Lifelong SLAM）解决机器人在长时间尺度（数月至数年）运行中的核心挑战：环境变化、地图增长、计算漂移和知识积累。与一次性SLAM不同，终身SLAM需要不断适应环境变化，同时保持对已学知识的有效利用。

## 2. 终身SLAM的核心挑战

### 2.1 环境变化类型

| 变化类型 | 示例 | 时间尺度 | 对SLAM的影响 |
|----------|------|----------|-------------|
| 短暂变化 | 行人、车辆 | 秒-分钟 | 动态物体处理 |
| 短时变化 | 家具移动 | 小时-天 | 地图更新 |
| 季节性变化 | 植被、光照 | 月-季 | 特征匹配失败 |
| 结构性变化 | 装修、改建 | 年 | 地图失效 |

### 2.2 核心问题

终身SLAM需要解决的几个关键问题：

1. **漂移累积**：长时间运行导致位姿漂移不断累积
2. **地图增长**：场景不断增大地图内存无限膨胀
3. **计算衰减**：随着地图增大，搜索和优化越来越慢
4. **变化检测**：识别环境中的新变化和旧变化
5. **遗忘与记忆**：决定哪些信息保留、哪些丢弃

## 3. 多会话SLAM

### 3.1 会话概念

多会话SLAM（Multi-Session SLAM）将运行过程分为多个会话（Session），每个会话独立运行SLAM，然后在会话间进行地图融合。

**会话定义**：
- **会话**：一次连续运行的SLAM过程（开机到关机）
- **全局地图**：跨会话融合得到的一致地图

### 3.2 会话间地图融合

**关键技术**：

1. **地点识别**：在新会话中识别旧会话访问过的位置
2. **相对位姿估计**：计算不同会话地图间的坐标变换
3. **地图合并**：将多个局部地图融合为全局地图
4. **全局优化**：对合并后的地图进行位姿图优化

**地图融合算法**：
```
会话A地图 ← → 地点识别(NetVLAD/DBoW) → 匹配候选
会话B地图 ← → 地点识别(NetVLAD/DBoW) → 匹配候选
                ↓
        几何验证(PnP/ICP) → 相对位姿 TAB
                ↓
        位姿图优化 ← 跨会话约束加入
                ↓
        全局一致地图
```

### 3.3 代表系统

| 系统 | 方法 | 特点 |
|------|------|------|
| ORB-SLAM3 Atlas | 多地图维护 | 自动创建/切换地图 |
| VINS-Fusion | 多会话定位 | 重定位回旧地图 |
| Kimera-Multi | 分布式多机器人 | 跨会话/跨机器人 |
| Maplab | 多会话建图 | 完整的建图平台 |

## 4. 增量式地图更新

### 4.1 变化检测

**方法**：
- **基于几何的变化检测**：比较新旧观测的几何差异
- **基于语义的变化检测**：比较语义标签的变化
- **基于时序的统计分析**：统计短期/长期观测的一致性

**变化检测流程**：
```
当前观测 → 与地图配准 → 计算残差 → 统计分布 → 变化判定
                                        ↓
                               显著性检验 → 变化区域标记
```

### 4.2 地图分层

将地图分为不同时间尺度的图层：
- **短期层**：最新观测，频繁更新
- **中期层**：聚合信息，周期性更新
- **长期层**：稳定结构，极少更新

### 4.3 更新策略

| 策略 | 描述 | 适用场景 |
|------|------|----------|
| 完全替换 | 用新观测替换旧地图 | 短暂变化 |
| 概率更新 | 贝叶斯融合新旧观测 | 持续观测 |
| 选择性更新 | 只更新变化区域 | 部分变化 |
| 版本管理 | 维护多版本地图 | 精确回溯 |

## 5. 地图压缩与管理

### 5.1 地图压缩

**方法**：
- **关键帧压缩**：去除冗余关键帧
- **特征压缩**：去除弱特征点
- **量化**：降低位置精度的存储位宽
- **稀疏化**：保留信息量最大的观测

### 5.2 信息驱动的关键帧管理

基于信息增益选择关键帧保留：

$$ \text{Score}(F_i) = \text{Information}(F_i) - \lambda \cdot \text{Redundancy}(F_i, \mathcal{F}_{\text{kept}}) $$

其中 $\text{Information}$ 衡量关键帧的信息量，$\text{Redundancy}$ 衡量与已保留帧的冗余度。

### 5.3 Boyer-Moore风格遗忘

机器人需要决定"记住什么"和"忘记什么"：
- **重要**：频繁访问区域的关键信息
- **次要**：较少访问的区域，只保留概要
- **临时**：临时物体的信息，可以丢弃

## 6. 持续学习与灾难性遗忘

### 6.1 问题定义

灾难性遗忘（Catastrophic Forgetting）：学习新环境时，模型会忘记之前学到的知识。

### 6.2 缓解策略

| 策略 | 方法 | 优缺点 |
|------|------|--------|
| 回放 | 存储旧样本用于重训练 | 需要存储，隐私问题 |
| 正则化 | 参数约束，防止大幅改变 | 限制学习能力 |
| 动态网络 | 为新任务扩展新分支 | 模型增长 |
| 模块化 | 不同场景不同模块 | 场景切换问题 |

### 6.3 在SLAM中的应用

- **模块化SLAM**：为不同环境类型维护不同参数/配置
- **特征池化**：维护一个跨环境的特征池
- **元学习**：学习快速适应新环境的先验

## 7. 长期运行的鲁棒性

### 7.1 退化检测

长时间运行中自动检测性能下降：
- 跟踪内点率持续下降
- 位姿不确定性增大
- 匹配质量下降

### 7.2 自动恢复

**恢复策略**：
1. **重定位尝试**：在当前帧搜索全局地图
2. **局部地图重建**：清除退化区域，重新建图
3. **全局优化**：检测到退化时触发全局BA
4. **回退模式**：降低运行模式，使用更鲁棒的配置
