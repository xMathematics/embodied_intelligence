# 10.2 机器人导航中的应用

## 1. 概述

机器人导航是SLAM最核心的应用领域之一。SLAM为机器人在未知环境中的自主移动提供定位和地图基础。

## 2. SLAM在导航中的角色

1. **定位**：机器人需要知道自己在哪里
2. **建图**：需要知道环境结构
3. **回环检测**：消除累积漂移
4. **地图更新**：处理环境变化

## 3. 导航栈

典型的机器人导航栈：

```
SLAM → 占据网格/ESDF → 全局规划 → 局部规划 → 控制
```

## 4. 室内机器人

- 家用扫地机器人
- 商用清洁机器人
- 仓储物流机器人

## 5. 室外机器人

- 自动驾驶汽车
- 巡检机器人
- 农业机器人
